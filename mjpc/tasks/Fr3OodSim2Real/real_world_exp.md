# FR3 실로봇 실험 — 기록할 데이터

Fr3OodSim2Real(learned-prior 주입) 실로봇 실험에서 로깅해야 할 데이터 정리.
실험: 학습 타겟 도달 → 타겟을 OOD로 step. 조건 3개(learned-only / warm-start /
cost-residual), 동일 파라미터, 각 1 trial.

> 원칙: **원시 데이터를 통째로** 저장(1 trial이라 재현 불가 → 나중에 어떤 지표든 재계산).
> 모든 로그와 카메라는 **하나의 시계로 동기화**(스트로보스코픽에 경로·숫자 정합용).

---

## 1. 로봇 상태 (권장 1 kHz)
| 채널 | 내용 | 용도 |
|---|---|---|
| `t` | 공통 타임스탬프 | 로그·카메라 동기 |
| `q[7]`, `qd[7]` | 측정 관절각·속도 | 상태, FK, sim2real |
| `tau[7]` | 측정(또는 명령) 토크 | 포화 확인, 저수준 검증 |
| `ee_pos[3]`, `ee_quat[4]` | EE pose (FK 또는 외부 mocap) | e_p, e_θ, 궤적, 거리 |

## 2. 제어 / 주입 (제어주기 ~50–100 Hz)
| 채널 | 내용 | 용도 |
|---|---|---|
| `q_d[7]` | 명령 관절각 (= ctrl, 플래너 출력) | 추종·모드 동작 확인 |
| `U_p[7]` (또는 청크) | ACT prior가 낸 q_d | prior가 계속 학습 타겟을 가리킨다는 증거(1·2 trap 원인) |
| `plan_ms` | 플래너 1 사이클 시간 | compute 주장(논문 main) |
| `ctrl_rate` | 실제 달성 제어주기 | 실시간성 |

## 3. 타겟 / 이벤트
| 채널 | 내용 | 용도 |
|---|---|---|
| `target_pos[3]`, `target_quat[4]` | 현재 타겟 | e_p, e_θ |
| `target_step_t` | ID→OOD 교체 시점 | 프로토콜 정렬, OOD phase 분리 |
| `events` | joint-limit 근접 / self-collision / e-stop·fault | 안전·타당성 |

## 4. 카메라
- 동기된 영상 + 프레임 타임스탬프 (스트로보스코픽 프레임 추출 + 로그 숫자/경로 오버레이).

## 5. 상수 (실행당 1회 기록)
- `K, H, σ, λ, α`, 저수준 PD gain (kp=[600 600 600 600 250 150 50], kd=[30 30 30 30 10 10 5]),
  주입 모드, 시작 자세(home), 학습 타겟·OOD 타겟 값.

---

## 후처리로 뽑는 지표 (위 원시 로그에서 계산)
- `e_p(t)`, `e_θ(t)` : 현재 타겟 기준, 그리고 **학습 타겟/OOD 타겟 각각까지 거리** → trap vs reach 곡선
- 조건별 **최종 OOD 타겟 거리** (figure에 넣는 숫자)
- 정착 시간, progress `p` (논문 metric)
- EE 궤적 (top-down X-Y; OOD step이 +y라 y가 성패 축)
