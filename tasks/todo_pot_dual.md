# 양팔 pot — Pick 구조 이식 계획 (2026-08-25, 계획만)

한팔 Pick에서 확정된 구조를 그대로 양팔 pot에 옮긴다. 원칙은 Pick과 동일:
**정착된 reach 태스크를 복사하고, phase는 cost를 바꾸지 않고 mocap 타겟만 옮긴다.**

## 0. 출발점 확인 (이미 있는 것)

- `Fr3HGripperDual` = 정착된 **양팔 reach**. per-arm 7항씩(L/R_pos 1e6, ori 6e5, cent 20,
  nsvel 5e3, vel 500, limit 5e6, ureg 0.01) + collision 5e5. K=128, H=0.4, knots 16,
  dt 0.03, adaptive sigma ON(min **0.10** = dual 정착 수정), **그리퍼 std 이미 0**(비샘플링).
  → Pick에서 손으로 껐던 "그리퍼 MPPI 제외"가 여기서는 기본값이다.
- `Fr3HGripperPot/pot.xml` = 냄비 free body(질량 합 ≈ 1.0 kg), 손잡이 프리미티브 충돌,
  파지 프레임 `pot_grasp_l` / `pot_grasp_r` 사이트 존재. 시각 mesh는 contype=0.
- 기존 `Fr3HGripperPot`(21항, per-arm softmax, 캐럿/firm-grasp 램프)은 **건드리지 않고**
  기록으로 남긴다 — Pick과 같은 이유로 그 구조를 패치하지 않는다.

## 1. 만들 것

새 태스크 `FR3_H_Gripper_PotDual` = `Fr3HGripperDual` 복사 + `pot.xml` include + phase.
- cost: Dual의 15항 **그대로**. 냄비 관련 항 없음.
- mocap: 0 = 왼손 타겟, 1 = 오른손 타겟(Dual에 이미 2개), 2 = **냄비 목표**(반투명 고스트) 추가.
- 파지점 = **`pot_grasp_l/r` 사이트 원점**(Pick의 "물체 로컬 원점"에 대응. 냄비 원점은 파지 불가).
- pre-grasp = 각 파지 프레임에서 접근축 방향 표면 여유 7 cm(Pick과 동일 규칙).

## 2. phase (양팔 공통 하나의 상태기계)

냄비는 하나이므로 phase는 **팔별이 아니라 쌍 단위**로 진행한다.
1. PRE-GRASP — 두 손 각각 자기 pre-grasp 점으로. 전이는 **AND**: 양쪽 모두 오차 15 mm &
   속도 0.06 m/s 미만을 0.2초.
2. APPROACH — 진입 시 각 팔의 하강 직선과 손목 자세를 latch, 두 가이드점이 **같은 진행률
   s_app**로 전진(연속 감속, 하드 게이트 금지). 도달 판정도 AND.
3. CLOSE — 0.25초 대기 후 두 그리퍼 명령을 동시에 닫기 값으로.
4. TRANSPORT — 0.3초 후 weld 활성화(아래 §3), 두 손 레퍼런스를 **같은 delta**로 이동
   (+z 5 cm 먼저, 그 뒤 목표까지). Pot의 대칭 리프트는 이 "같은 delta"로 구조적으로 보장.
5. DELIVERED — 냄비가 목표 10 mm 안 0.3초 유지.
실패 경로: 닫기 후 2초 미확인 → PRE-GRASP 재시도(weld off). 운반 중 상실 판정은 weld를
쓰면 불필요.

## 3. 결정해야 할 것: weld를 몇 개 걸까 (핵심)

Pick은 weld 하나로 미끄러짐이 사라졌다. 양팔은 손잡이 2개라 선택이 갈린다.

| 안 | 내용 | 위험 |
|---|---|---|
| A | **양쪽 다 weld** | 두 팔 + 냄비가 **닫힌 사슬**이 된다. 두 팔의 추종오차 차이가 전부 내부 구속력으로 간다(사용자가 처음 지적한 과제약). 두 레퍼런스가 같은 delta로 움직이므로 명목상은 일관되지만, 실제 오차 차이만큼 팔이 서로 버틴다. soft `solref`로 완화 가능 |
| B | **한쪽만 weld**, 반대쪽은 마찰 파지 | 닫힌 사슬이 없다. 대신 마찰쪽이 미끄러질 수 있다(현재 패드 μ=2, 40 N) |
| C | weld 없음(마찰만) | 가장 물리적. 기존 Pot 작업에서 미끄러짐이 문제였던 그 조건 |

권장: **A를 soft solref로 먼저**, 팔이 서로 버티는 게 보이면 B. C는 A/B가 안 될 때만.

## 4. Pick에서 가져올 수치와 재조정 필요분

- phase 3 위치 가중: Pick은 `Reach_pos` ×5로 처짐(40~60 mm)을 해결. 냄비는 1.0 kg(박스의
  2배)이고 팔에서 더 멀리 잡으므로 **×5부터 시작해 필요하면 상향**(L/R 동시에).
- 레퍼런스 속도: phase 2 `v = max(0.01, 1.0×남은거리)`, phase 3 `min(0.25, max(0.03, 3.0×d))`.
- 하드 게이트 금지, 게이트 임계값과 도달 판정은 **별 파라미터**.
- 파지 확인은 weld 시점(시간 기반) — 개구 창/접촉 판정 불필요.
- K는 Dual 기본 128에서 시작(1회 비용이 Pick보다 크다: nu=16). 느리면 64로.

## 5. 검증 순서

1. GUI에서 phase 1→2→CLOSE→TRANSPORT 진행 확인(사용자 확인이 합격 기준).
2. 냄비 교란(무접촉 하한 측정), 대칭 리프트(양 손잡이 z 차이), 종단 오차.
3. 최소 3시드, 결론용은 6시드. **단발 런으로 결론 내지 말 것**(Pick에서 같은 시드가
   손 속도 0.02~0.40 m/s로 갈렸다).
